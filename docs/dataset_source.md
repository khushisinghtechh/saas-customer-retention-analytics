# Dataset Source and License

- Dataset: [SaaS Customer Churn Dataset](https://www.kaggle.com/datasets/mounikabusi/saas-customer-churn-dataset)
- Source author: Mounika Busi
- Dataset license shown on Kaggle: Apache License 2.0
- Data status: synthetically generated for education and portfolio practice; not real customer records
- Extracted size: approximately 1.67 MB across six CSV files

The raw CSV files are source copies downloaded from Kaggle and are excluded from this repository. Cleaned outputs can be reproduced by running `src/clean_data.py` after obtaining the dataset from its source. Preserve the dataset attribution and license when redistributing the data. The project code and dataset have separate licenses.
